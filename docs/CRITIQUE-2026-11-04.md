## 0. Executive Triage, Guardrails & Developer Pushbacks

### 0.1 Where the Developer Panel Pushed Back on Critics (Read Before Patching)
1. **No MVVM / Hilt / Room / Jetpack DataStore / Redis rewrites:** Every verified race, socket leak, and UI bug below resolves cleanly inside existing Kotlin/Node classes (`~34 net LOC` for the core `MainActivity`/`BERTAlerts`/`YouProfile`/`build.gradle.kts` set) with zero new dependencies.
2. **Do NOT add coroutine `delay(300)` debouncing to `YouScreen.kt:125-128`:**
   - `YouProfile.setName` (`YouProfile.kt:18`) already uses `.apply()` (sub-microsecond in-memory map update + coalesced background write), not `.commit()`.
   - `YouScreenTest.kt` synchronously asserts `YouProfile(compose.activity).name()` on the line immediately following `performTextReplacement(...)` in **9 host tests** (`lines 128, 443, 445, 458, 463, 466, 483, 489, 494`), and `NoticeboardSheet` (`HomeScreen.kt:234`) reads `name()` synchronously on open. Hoisting `Regex("\\s+")` + a `CharArray` pass + skipping no-op `setName` calls removes 100% of the allocation churn without breaking a single test.
3. **Do NOT render portfolio PnL on `HomeScreen.kt:84`:** Keep `Home` as Bert's calm pixel garden (`YouScreen.kt:153` deliberately shows `"Set up"` rather than dollar balances for shoulder-surfing privacy). Simply delete the unused `position: BERTPosition` parameter on `HomeScreen.kt:84`.
4. **Do NOT switch `BERTPlaceWidget` (`PlaceStamp.render`, `BERTPlaceWidget.kt:101`) to `RGB_565` or drop `SizeMode.Exact`:**
   - On `minSdk = 26+`, Bitmaps cross IPC via `ashmem` FDs (not inline in the `1 MB` Binder buffer); the actual OS guardrail is `AppWidgetServiceImpl`'s `RemoteViews.estimateMemoryUsage()` (`1.5x` screen bytes across `SizeMode.Exact` orientations).
   - `RGB_565` causes visible 5/6-bit Mach banding on dusk/night sky gradients in `place_wide_*`. Keep `SizeMode.Exact` + `ARGB_8888`, cap integer pixel scale `k` so `cropW * k * cropH * k <= 360_000` (`<= 1.4 MB` max, typically `496x496 = 984 KB`), and `.recycle()` decoded intermediates (`65-75%` RAM cut, zero banding).
5. **Do NOT change `formatPrice` (`Formatters.kt:12-14`) globally from 4 to 5-6 decimals:**
   - Widening widget price strings from 7 to 8-9 glyphs at `24.sp` bold overflows `120x120dp` and breaks `BERTWidgetRenderTest.compactWidgetFitsFromMinimumToLarge` (`BERTWidgetRenderTest.kt:157`). Fix trailing-zero jitter globally (`minimumFractionDigits = digits`) and add `precise: Boolean = false` (`5` digits on `MarketScreen`, `4` on compact widgets).
6. **Never proxy Solana wallet lookups through `berthalla.io`:** Keep `berthalla.io` zero-knowledge of user wallets. Staked Berts in `MyBert.kt` can be verified directly on public `api.mainnet-beta.solana.com` via standard `getMultipleAccounts` + MPL Core binary layout (Section 5.1).
